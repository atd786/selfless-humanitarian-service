# Selfless Humanitarian Service

Official web application for **Selfless Humanitarian Service**, an SECP-Registered National NGO in Pakistan.

## Projects & Initiatives
- **High School for Underprivileged Children**: Providing high-quality English-medium education and daily nutrition in Shahdara, Lahore.
- **Technical Training Institute**: Vocational and skill-development training center empowering marginalized youth.

## Tech Stack
- **Framework:** React 18
- **Tooling / Bundler:** Vite
- **Deployment Target:** Hostinger Web Apps / Cloud Hosting

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
The output will be generated in the `dist` folder.
